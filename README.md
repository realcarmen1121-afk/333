貓的肝病用藥量計算

貓的肝病用藥量需要依據貓的體重及藥物種類做精確計算，劑量過多超過貓咪肝臟所能代謝的量，可能加劇肝的壞死與衰竭，劑量太少則無法改善病情，因此需要計算出最低有效劑量及最高安全上限，確保用藥安全。由於每種藥物，例如抗生素、類固醇都有不同的劑量，此程式透過輸入體重及藥物種類，可以讓獸醫師正確快速的計算出用藥量，減少錯誤的風險，並換算成藥錠顆數，方便飼主給藥。

本程式以「安全防呆、動態運算、實務轉換」為核心運作思維，依序執行以下三個步驟： 
輸入與防呆檢核： 接收使用者輸入的體重與藥物種類，並透過邊界篩選（過濾 0.5~15kg 以外的異常數值），防止人為誤輸入導致的劑量風險。
動態劑量區間運算： 根據選定藥物自動對應獸醫藥理係數（mg/kg/day），精確計算出「最低有效劑量」與「最高安全上限」，確保用藥安全。
居家照護實務轉換： 將毫克數（mg）對應市售規格，自動換算為具體的藥錠切片與顆數建議，解決飼主實務給藥的痛點。
